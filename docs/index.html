ENGINEERING CASE STUDY

把缺失資料，變成
可依賴的查詢流程。

v3.2.1 的修正核心不是換一層介面，而是建立穩定的資料契約：從檔案讀取、欄位清理到 API 輸出，每一步都能被驗證。

  1. 01
    讀取來源標準檔名與舊檔名自動回退
  2. 02
    清理資料BOM、空白、價格符號與型別
  3. 03
    穩定輸出固定 API 欄位，不受額外 index 影響
  4. 04
    完成決策關鍵字、預算、店家連動與排序
